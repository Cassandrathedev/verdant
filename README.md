# Verdant

A responsive landing page for Verdant, a fictional farm-fresh grocery delivery brand. Built as my second assignment for the TechCrush bootcamp, recreated from a given UI design using only HTML and CSS (no JavaScript).

## Live Demo



## Sections

- Header with logo, navigation, search and basket
- Hero with ZIP code input, ratings and featured harvest box
- Shop by craving (aisle cards)
- How Verdant works (three steps)
- Fresh off the truck (product cards with filters)
- Promotional banners
- Footer

## Built With

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Google Fonts: DM Sans and Source Serif 4
- Phosphor Icons
